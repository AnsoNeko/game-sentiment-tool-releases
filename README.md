# 项目舆情与运营支持工具

这是“项目舆情与运营支持工具”的公开更新与发行仓库，仅用于发布版本说明和 Windows Release 安装包，不包含项目源码、业务数据库或用户配置。

## 最新版本

- 版本：`v0.3.4`
- 平台：Windows x64
- 形式：NSIS 安装程序
- 下载：[前往最新 Release](https://github.com/AnsoNeko/game-sentiment-tool-releases/releases/latest)

> v0.3.4 将反链多关键词采集改为“首词主关键词、其余副关键词”的逐主页兜底规则；副关键词找到的候选必须由主关键词匹配作品真实标签后才会保存。

## 使用方式

1. 在最新 Release 页面下载 `GameSentimentTool-v0.3.4-win-x64-Setup.exe`。
2. v0.3.3 用户可直接使用软件内更新升级到 v0.3.4。**v0.3.2 及更早版本必须手工下载 v0.3.4，并以管理员身份运行一次。** 旧版更新助手会在新的安装握手代码生效前自行退出，无法通过远端资源反向修复。
3. 安装程序检测到旧版本时会自动沿用原安装路径，全新安装使用默认目录。
4. 软件的项目、评论、Cookie、安全配置和 AI 配置均保存在当前 Windows 用户的本地应用数据目录中，不会存入本仓库。

当前版本未进行代码签名，Windows SmartScreen 可能显示未知发布者提示。请只从本仓库的 Release 页面下载，并可使用下列 SHA-256 校验文件：

```text
4C34D5D0FE0A83D1B1B0F0C606FFB257C7269F7C300EE1C6166C6B7BDFD9E3E3
```

## 更新检查

软件内置本仓库地址，通过 `latest.json` 严格校验版本、固定下载地址、大小和 SHA-256 后才允许安装。v0.3.3 起，应用先请求管理员权限并确认 NSIS 已启动，再退出旧客户端；取消 UAC 或安装助手未就绪时客户端保持运行。检查更新不会上传本地项目数据、玩家评论、Cookie、API Key、Prompt 或安全设置。

版本变化请查看 [CHANGELOG.md](CHANGELOG.md)。
